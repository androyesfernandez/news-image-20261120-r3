One broadsheet poster carrying the whole of Friday 20 November 2026: 46 stories from 8 regions, 13 of them drawn as full scenes — Russian missiles hitting three Kyiv bridges, Cyclone Akvan's landfall in Odisha, the AI sell-off that sank Asia's markets (Taiex −17.5% on the week), COP31 ending without a deal, a UK–EU reset, BepiColombo's arrival at Mercury, Kenya's first oil well and a cancer pill that shrank tumours in 60.7% of patients. A UTC timeline, six big numbers, a dotted world map with pins for every drawn story and a DATE CHECK box that keeps Thursday's news — and Saturday's — out.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the poster to `out/entry.png`. The program uses only the Python standard library.
